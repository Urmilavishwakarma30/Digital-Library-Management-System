# Digital-Library-Management-System
A web-based Digital Library Management System built using Spring Boot, MySQL, JPA, Spring Security and Thymeleaf.

## 📌 Project Description

Digital Library Management System is a web-based application developed to manage library books and provide a simple and secure digital library system.

The project is developed using Spring Boot and provides database connectivity using MySQL and JPA. Thymeleaf is used for the web interface and Spring Security is used for authentication and security.

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- Thymeleaf
- MySQL
- HTML & CSS
- Maven
- Eclipse IDE

## ✨ Features

- User Login and Authentication
- Secure application using Spring Security
- Book Management
- Add, Update and Delete Book Details
- View Books
- MySQL Database Integration
- JPA for Database Operations
- Thymeleaf-based Web Pages

## ▶️ How to Run

1. Install Java JDK, MySQL and Eclipse.
2. Open the project in Eclipse.
3. Create the required database in MySQL.
4. Configure the MySQL username, password and database name in:
   
   `src/main/resources/application.properties`

5. Update the database configuration according to your system.
6. Run the main Spring Boot application class.
7. Open the browser and visit:

   `http://localhost:8080`
